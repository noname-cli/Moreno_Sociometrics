# Берегите свое время
Утилита для автоматизации обработки социометрии по Морено
Интерфейс графический. Реализованы функции ввода первичных данных, их обработки и сохранения проектов. Производится автоматический расчет индексов, разделение учащихся по статусным категориям и группировка по взаимным выборам. Вся аналитика может экспортироваться в тестовые и табличные документы.
